\## ⚙️ How to Compile and Run



Every program is standalone and takes its input from the console.



```bash

g++ -o bubble\_sort bubble\_sort.cpp

./bubble\_sort

```



On Windows, run the generated `bubble\_sort.exe` instead. No external libraries are needed, only the C++ standard library.



\## 📊 Complexity Summary



| Practical | Algorithm | Time Complexity | Space Complexity |

|-----------|-----------|-----------------|------------------|

| 1 | Bubble / Selection / Insertion Sort | O(n²) | O(1) |

| 1 | Merge Sort | O(n log n) | O(n) |

| 1 | Quick Sort | O(n log n) average, O(n²) worst | O(log n) |

| 2 | Linear Search | O(n) | O(1) |

| 2 | Binary Search | O(log n) | O(1) |

| 3 | Heap Sort | O(n log n) | O(1) |

| 4 | Factorial | O(n) | O(1) iterative, O(n) recursive |

| 5 | 0/1 Knapsack | O(n × W) | O(n × W) |

| 6 | Matrix Chain Multiplication | O(n³) | O(n²) |

| 7 | Making Change | O(amount × coins) | O(amount) |

| 8 | DFS and BFS | O(V + E) | O(V) |

| 9 | Prim's Algorithm | O(V²) | O(V²) |

| 10 | Kruskal's Algorithm | O(E log E) | O(V + E) |

| 11 | Floyd–Warshall | O(V³) | O(V²) |

| 12 | Travelling Salesman (DP) | O(n² × 2ⁿ) | O(n × 2ⁿ) |
